# Marketing docs — Chatbot knowledge base

This folder is the **knowledge base the site chatbot reads**. Content is extracted from the Brand Playbook and written in the playbook's tone and vocabulary: calm authority, benefit-forward, approved terminology (e.g. autonomous, handles, guest experience — never chatbot, automated, or competitor names).

## Structure

- **`en/concepts/`** — Content blocks the chatbot retrieves and returns: what Alfred is, value and pillars, benefits for hosts, benefits for guests, product facts, vocabulary reference, example phrases.
- **`en/procedures/`** — Q&A answer blocks: ready replies for "What is Alfred?", setup questions, objections, how Alfred is different, features and benefits.

## How the chatbot uses it

- **Concepts** = paragraphs and sections to answer "what is Alfred?", "what do I get?", "what do my guests get?", "what are the facts?".
- **Procedures** = exact answers for specific questions or objections (e.g. "How long is setup?" → the block from setup-answers.md). The chatbot matches the visitor's question to the right file and section, then returns that text.

All text is **direct content** in playbook tone — not instructions like "when you talk to the host use this language." The files are what the chatbot reads and says.

## Source

Extracted from `BRAND_PLAYBOOK_MASTER_EN_v1_2.txt`. Excluded: internal governance, visual identity, decision registers, competitor names, long channel playbooks.

## Language

English (en) only. Localized playbooks (IT, ES, FR) can be used to add localized concept and procedure content later.
